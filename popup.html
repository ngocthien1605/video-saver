On Windows, paste commands into PowerShell (not cmd.exe). On macOS/Linux, use a POSIX shell.

Signed links (?Expires=…&Signature=…) can expire within minutes, and yt-dlp can't renew them partway through a download. For long videos, use the Open button instead, which fetches fresh links automatically. Run it within a few minutes (signed links expire), on this same computer and network. The cookies file holds your login cookies, so keep it private and delete it afterwards. If you still get a 403, the site is probably checking the browser's network fingerprint. In that case, install pip install "yt-dlp[default,curl-cffi]" and add --impersonate chrome, or use the extension's Open or Download button instead.
